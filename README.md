# Faber for Windows

Official Faber installers for Windows 10 and 11. This repository distributes binaries only.

[Download Faber](https://github.com/Dyu-36/Faber-releases/releases/latest/download/Faber-setup.exe)

Visit [faber.lgmmo.click](https://faber.lgmmo.click/) for product information and pricing.
Contact [Duy on Zalo](https://zalo.me/0981652816) for activation and setup support.

The installer includes the Faber desktop app, its OpenCode core, and third-party license notices.
Each release includes a SHA-256 checksum for the installer.
